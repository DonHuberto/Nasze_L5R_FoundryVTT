Personal use fork of official Foundry VTT module for L5R: https://gitlab.com/teaml5r/l5r5e

Custom changes:
- Rolls
  - LMB to keep, RMB to discard  
  - Expanded roll summary  
  - Support for strife and fatigue to actor and target  
  - Roll automation:
    - Support for Void, Air, and Fire stance  
    - Auto TN adjust for conditions  
    - Support for Bleeding and Intoxicated conditions  
    - Mark strife dice as discarded while Compromised
